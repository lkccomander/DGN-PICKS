# DGN-PICKS Branding

## Name
`DGN-PICKS`

## Visual direction
Professional sportsbook-style analytics interface: dark, dense, high-information, clean, modern.

Pinnacle is visual inspiration only. Do not copy its logo, code, assets, proprietary text, odds, or exact layout.

## Approved brand treatment
- White bold geometric/interlocking wordmark.
- Dark navy application background.
- Under-logo stripe order: **blue → white → red → white → blue**.

## Initial palette
- Navy: `#0B2A4A`
- Blue: `#0085FF`
- White: `#FFFFFF`
- Red: `#E3222E`
